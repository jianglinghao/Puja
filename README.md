# 🧸 智能毛绒玩具本地伴侣 Node.js 服务端运行指南

这是一个为您的智能玩具提供“智脑”的纯 Node.js 服务。整个服务设计为“无头模式（Headless）”，不需要任何浏览器页面，笔记本盖子合上放在房间角落即可运行。

---

## 💻 1. 笔记本电脑前置要求 (以 Mac OS 为例)

1.  **系统录音组件 (sox)**:
    主程序的录音引擎依赖底层的 `rec` 命令。请先在您的终端中运行以下命令安装：
    ```bash
    brew install sox
    ```

2.  **默认音频设备设置**:
    *   将毛绒玩具内的蓝牙音频主板开机，并在 Mac 的**蓝牙设置**中将其连接。
    *   在 Mac 的 **系统声音设置** 中：
        *   将 **输入 (Input)** 设备设为：`毛绒玩具的蓝牙麦克风`
        *   将 **输出 (Output)** 设备设为：`毛绒玩具的蓝牙喇叭`

---

## ⚙️ 2. 本地服务配置

### ① 声音克隆 (GPT-SoVITS) 配置
本服务调用本地 `http://127.0.0.1:9880` 端口的声音克隆服务。
*   在您的闲置笔记本上先开启已训练好您声音的 GPT-SoVITS API 推理接口。
*   确保能够通过 `GET http://127.0.0.1:9880/?text=你好&text_language=zh` 获取合成的音频。

### ② 环境变量配置 (`.env`)
项目根目录下的 `.env` 文件保存了核心的 API 配置，请根据您的实际密钥进行填写：
```env
# 大模型 API 配置 (DeepSeek 或 豆包)
LLM_API_KEY=您的_API_KEY
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
```

### ③ 记忆配置 (`src/user_profile.json`)
在该 JSON 文件中填写您孩子的真实信息，大模型会自动记忆并在日常对话中适时提起：
```json
{
  "userName": "天天",
  "favoriteToy": "霸王龙",
  "pet": "小猫咪咪",
  "birthday": "10月20日"
}
```

---

## 🚀 3. 运行玩具进程

在项目根目录下，直接执行守护启动脚本：
```bash
./scripts/start-toy.sh
```
该脚本会自动进入死循环守护状态，如果服务因蓝牙信号断开、网络异常意外退出，将会在 3 秒后自动拉起重启，确保玩具 24 小时在线。
